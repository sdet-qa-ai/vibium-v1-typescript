# 🚀 Vibium with TypeScript – Complete Tutorial (Mocha)

This repository is part of the SDET x AI YouTube series, where we explore next-generation browser automation using AI-first tools.

In this project, we build a TypeScript-based test automation setup using Vibium and Mocha, and understand why traditional browser automation struggles in the AI era.

## 📌 What You'll Learn

In this tutorial, you will learn:

- What Vibium is and why it exists
- Problems with traditional browser automation
- How Vibium solves automation challenges using AI
- How to set up a TypeScript automation project
- How to write and run Mocha tests in TypeScript
- Project structure and best practices for SDETs

## 🧠 Why Vibium?

Traditional browser automation tools:

- Break frequently due to DOM changes
- Rely heavily on brittle selectors
- Are hard to maintain at scale

Vibium is designed for the AI era, focusing on:

- Intelligent interactions
- Reduced flakiness
- Better abstraction for browser behavior
- Future-ready automation using AI concepts

## 🛠 Tech Stack

- Node.js
- TypeScript
- Mocha – Test Runner
- Chai – Assertions
- ts-node – TypeScript execution
- Vibium – AI-powered browser automation
